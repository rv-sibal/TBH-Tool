# TBH Tool

A Windows app for **TBH: Task Bar Hero**: installs the mod, tuning sliders,
auto-open chests, auto-corrosion and gold / hero changes.

## Download

Get `TBH-Tool.zip` from the [latest release](https://github.com/rv-sibal/TBH-Tool/releases/latest),
unzip it anywhere and run `TBH-Tool.exe`. The README.txt inside explains the rest.

The app updates itself: when a new version is out it asks to restart, or
updates when you close it. Your settings are kept.

Windows may warn that the app is from an unknown publisher (it is not code
signed): click "More info" then "Run anyway".
